## Key Concepts

### Variables
`let` can be reassigned, while `const` cannot be reassigned.

### Data Types
JavaScript includes String, Number, Boolean, Undefined, Null, Object and other types.

### Conditions
`if`, `else if` and `else` are used to make decisions.

### Loops
`for`, `while` and `for...of` are used to repeat code.

### Functions
Functions are reusable blocks of code.

```js

function add(a, b) {
    return a + b;
}
